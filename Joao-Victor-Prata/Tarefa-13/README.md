# Tarefa 13 - Projeto CRUD

Implementação de um projeto CRUD de (...) com front-end e back-end

## Como rodar o projeto
Para instalar e rodar este projeto, clone este repositório e navegue para a pasta do projeto ([projeto-crud](https://github.com/joviprata/trainee3/tree/Tarefa-13-Joao-Victor-Prata/Joao-Victor-Prata/Tarefa-13/projeto-crud)). Instale as dependências rodando o seguinte comando no terminal:


```bash
npm install
```

Em seguida, rode o seguinte comando no terminal para iniciar o projeto:

```bash
npm start
```
