# Tarefa 12 - Implementação de formulário usando Reactive Forms

- Criação de um formulário de dados de clientes usando o Reactive Form no Angular
- Criação de um campo multivalorado FormArray, "telefones"
- Criação de um caso de teste com FormRecord

## Como rodar o projeto
Para instalar e rodar este projeto, clone este repositório e navegue para a pasta do projeto ([projeto-forms](https://github.com/joviprata/trainee3/tree/Tarefa-12-Joao-Victor-Prata/Joao-Victor-Prata/Tarefa-12/projeto-forms)). Instale as dependências rodando o seguinte comando no terminal:


```bash
npm install
```

Em seguida, rode o seguinte comando no terminal para iniciar o projeto:

```bash
npm start
```
