# Tarefa 11 - Implementação de formulário usando Template-Driven Form

Implementação de um formulário de dados de clientes usando o Template-Driven Form no Angular.

## Como rodar o projeto
Para instalar e rodar este projeto, clone este repositório e navegue para a pasta do projeto ([projeto-forms](https://github.com/joviprata/trainee3/tree/Tarefa-11-Joao-Victor-Prata/Joao-Victor-Prata/Tarefa-11/projeto-forms)). Instale as dependências rodando o seguinte comando no terminal:


```bash
npm install
```

Em seguida, rode o seguinte comando no terminal para iniciar o projeto:

```bash
npm start
```
